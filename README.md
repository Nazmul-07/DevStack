# 🚀 DevStack

> **Build Your Ideal Development Stack**

DevStack is a modern and interactive web application that helps developers explore different technologies and build their ideal development stack. Users can discover technologies across different categories and select the tools that best fit their projects.

## 🛠️ Technologies Used

* ⚛️ **React**
* 🟦 **TypeScript**
* 🎨 **Tailwind CSS**
* 🌼 **DaisyUI**
* ⚡ **Vite**
* 🔔 **React Toastify**
* 🎯 **React Icons**

## ✨ Features

### 1. 🔎 Explore Technologies

Explore different frontend, backend, database, and development tools with useful information such as category, difficulty, rating, and description.

### 2. 🧩 Build Your Own Tech Stack

Select technologies and create a personalized development stack based on your project requirements.

### 3. ⚡ Interactive Stack Management

Selected technologies are automatically disabled from the available list, and the **Add to Stack** button becomes active again when a technology is removed.

## 🎯 Project Goal

The main goal of DevStack is to provide developers with a simple and interactive platform for exploring technologies while practicing modern frontend development concepts.

## QUESTION ANS:


### 1. What is JSX, and why is it used in React?

JSX is a syntax that give us to write HTML-like code inside JavaScript or TypeScript. It makes React UI code easier to read and write.

### 2. What is the difference between props and state?

 Props are used to pass data from a parent component to a child component.
 State is used to store data inside a component and change it when needed.

### 3. What does the `useState` hook do, and where did you use it in this project?

useState is used to store and change data in a component.

I used it to store the selected technologies in my project.

### 4. What does the `useEffect` hook do, and why did you need it to load the JSON data?

useEffect runs some code after the component loads.

I needed it to load the JSON data so the technology information can be displayed dynamically in the app.

### 5. Why does every item in a `.map()` list need a unique `key` prop?

The key helps React identify each item in a list.

It helps React update the list correctly.

### 6. What is conditional rendering? Show one place you used it.

Conditional rendering means showing something based on a condition.

I used it to show a message when the selected technology list is empty, botton text change, Remove all btn etc.

### 7. How do you pass data from a parent component to a child component, and how does a child send something back to the parent?

A parent passes data to a child using **props**.

To send something back, the parent can pass a function as a prop. The child calls that function when an action happens.
